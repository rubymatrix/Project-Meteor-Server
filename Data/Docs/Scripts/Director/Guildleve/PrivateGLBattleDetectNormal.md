# PrivateGLBattleDetectNormal: battle leve director

Script: [`Data/scripts/Director/Guildleve/PrivateGLBattleDetectNormal.lua`](../../../../scripts/Director/Guildleve/PrivateGLBattleDetectNormal.lua)

`init` returns: director path, director id (0x4e25), guildleve id, aetheryte location (6 or ~6),
exit marker x, y, z.

| Id | Leve |
|---|---|
| 22 | Limsa battle leve |
| 14 | Gridania battle leve |
| 26 | Ul'dah battle leve |
| 16 | Coerthas faction leve |
| 72 | Harvest leve |
