# PrivateGLBattleTutorial: battle leve tutorial director

Script: [`Data/scripts/Director/Guildleve/PrivateGLBattleTutorial.lua`](../../../../scripts/Director/Guildleve/PrivateGLBattleTutorial.lua)

exit marker x, y, z.
