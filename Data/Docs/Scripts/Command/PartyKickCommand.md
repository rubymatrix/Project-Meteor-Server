# PartyKickCommand: text ids

Script: [`Data/scripts/Command/PartyKickCommand.lua`](../../../scripts/Command/PartyKickCommand.lua).

Game message text ids for ousting a party member:

- 30404: ousted (sheet/actor id version)
- 30410: you are ousted
- 30428: ousted (string version)
- 30540: you are not the party leader
- 30555: unable to oust
- 30575: cannot oust, not a party member
